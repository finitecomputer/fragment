# simplex

SPIKE (branch spike/simplex-door, never merged): the SimpleX connector, a
hosted door like Telegram's (templates/telegram), whose other end is the
platform's SimpleX door: a small container of its own, always on, running
SimpleX's core, its databases saved to its Durable Object after every
change (cell/door.mjs, images/simplex-door). Results: the Linear document
"SimpleX door spike: results".
