# The import prompt

What a person sends their new agent at finite.chat, with their old
agent's export (move.finite.place) attached, or its Google Drive link.
Paste it as it is, changing only the answers.

```
Please bring my old agent over from finite.computer: use the
import-agent-home skill on the zip I attached (layout finite-computer).

My answers:
- Keep its name and picture: yes
- Keep its public sites public: no
```

For a Google Drive link, write "on the zip at <the link>" in place of
"on the zip I attached".

The agent asks nothing more, does it all, and ends with one message
saying what came over, what didn't and why, and what is left for the
person to do.

Later, for the old agent's sites on finite.site alone (its key must be in
the person's Vault for the new agent, toward finite.site):

```
Please bring my old agent's sites over from finite.site with the
import-agent-home skill.

Make these public: garden
```

Leave out the last line to keep them all private.
