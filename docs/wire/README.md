# The wire

Generated by `cargo xtask wire` from crates/proto (its `src/routes.rs` and
the types it names): edit those, never this file. [docs/api.md](../api.md)
says what each route means, who may call it and its limits;
`crates/proto/wire.lock` holds what an older client relies on
(`xtask/src/wire/lock.rs`). The same as OpenAPI 3.1: [openapi.json](openapi.json).

in. `POST /api/migrations/mover/agents/{old}/report`: what happened on the command it names.
